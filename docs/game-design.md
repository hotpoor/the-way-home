# 来时的路：游戏设计 v0.2

## 叙事承诺

老妇人回乡取旧学校留下的画册。她始终保持老年形象，往日人物保持记忆中的年龄。黑狗是现实与回忆之间的同行者。不预设黑衣代表丧偶，也不擅自决定未确认的感情结局。

视觉以秋日乡村参考画为基准：金色麦田、灰绿山坡、红顶白墙、暖纸色天空，保留笔触。界面像画册页边注，避免任务面板铺满画面。Three.js 使用正交相机和绘画平面，后续逐步拆分前中后景，加入受控视差与地形连接。

核心循环：走到一个旧地点 → 通过生活动作参与回忆 → 听见一句旧话 → 拾取画册一页 → 继续赶路。轻度解谜，不用战斗和惩罚性失败推动故事。

## 首章验收

可以从标题启程，行走至树下，三次敲树，拾起三颗核桃，完成回忆。重载保持位置和任务状态。导入严格验证版本、坐标、收集索引；存储不可用仍能游玩并提示导出。移动端支持触控。GitHub Actions 测试、构建并发布 Pages。

## 下一轮美术与交互

优先：女主与黑狗的手绘透明动作素材；拆分山丘、树冠和前景；敲击反馈、角色朝向与更自然步态；核桃可见性与拾取指引；第一章后加入枣树护理。需要保留手绘轮廓，避免改成低多边形 3D。

### 第一章试玩修订

已接入老妇人与黑狗的透明手绘八帧行走图集、左右朝向、敲树竹竿反馈、核桃描边提示。屏幕适配覆盖窄屏、手机横屏、桌面和超宽屏：相机保持比例并跟随、动态视口和安全区、触控与互动分区、可滚动手记、条件显示全屏。仍需后续用视频抠像进一步提升自然动作，以及制作专用敲树与拾取动作。

### 连续视频步态修订

原八帧图集存在不连续姿态与滑步问题。老妇人已改为本地 ComfyUI H3 视频的 58 帧连续循环（24fps，20–77 帧），使用纯绿背景和相同首尾帧约束。统一裁剪、脚底锚点和方向翻转，步态相位按行走距离推进；56 世界单位/循环使角色移动速度约 23.17 世界单位/秒，与原视频脚掌后移速度相匹配。停下切换首帧站姿。黑狗的原图集暂未换成视频，专用敲树/拾取动作仍待制作。

### 黑狗与停步动作修订

黑狗随后改为本地 H3 的 32 帧连续行走循环，按它自己的移动距离推进相位。两位角色另有独立视频待机：老妇人停稳 4.5 秒后理耳边头发、放下手站稳；黑狗停稳 2.5 秒后坐下、摆尾、抬后腿挠颈侧，再站起。两段分别为 124 和 175 帧，单次播放后冷却 13/11 秒。移动输入触发收尾，奶奶先放手、狗先起身再行走；敲树、拾取优先于奶奶的待机动作。菜单暂停进度。

相关素材使用相同的世界缩放和水平中心，并对齐落地基线。图集限制在 4096×4096 内，兼顾移动端。首轮低尺寸黑狗样片因闪烁未采用，合格原片使用 576×384。专用敲树、拾取动作仍待制作。

## 制作工具候选

静帧首轮使用 GPT imagegen；用户提出可考虑 Qwen Image 2.1。视频可考虑用户提出的 MiniMax H3，但模型名称、接口支持、二次采样加速和超分需后续查官方文档确认。不把未核实能力写进产品承诺。核心交互始终实时渲染。

## 外部技能参考评估

参考仓库：<https://github.com/gamedev-skills/awesome-gamedev-agent-skills>，评估版本 `184b72be02884f782a0058f2eeae2ce4277453e4`。读取 `threejs-scene-setup`、其 `scene-graph` 参考，以及 `save-systems`。

采用：`setAnimationLoop`、受限设备像素比、调整投影矩阵、正交绘本场景；只保存纯数据、版本号、输入校验、异常反馈和重载验收。当前 Three.js 锁定 r180，技能的 r186 示例按实际安装版本判断，不照搬新版 API。存档为浏览器 localStorage，不照搬文件系统临时文件重命名。未引入 OrbitControls，以保留既定叙事镜头。

这些文档对工程检查有帮助；美术与关卡没有交给通用模板决定。本轮不全量安装技能、不增加运行时依赖。


## 第二章：枣树下的光（可玩原型）

第一章结束页可进入，也可从手记往返。独立的乡村院落背景继续使用原老妇人和黑狗的连续视频动作。到树下打开护理画册：初夏辨认成年健壮树并标出环切示意，夏日疏去较小拥挤果，冬日选择交叉枝与枯弱枝，翌春观察异常簇生枝并选择先请人确诊。无时间惩罚，错误选择有具体反馈。剪枝回忆保留秋千旧绳的叙事。

每一步都会写入现有 v1 存档中的 `garden`，`chapter` 表示所在场景；旧存档缺少字段时自动补齐，不丢第一章。完成第二章后可收取第二页记忆，并往返两个场景。手记与标题说明更新为两章试玩，上学路为下一轮。

护理画板是便于鼠标、触摸和键盘操作的简化 SVG 示意，不模拟刀口深度或给出药物方案，也不表现病树当场痊愈。不同季节明确分开，避免把环切、疏果、冬剪拼成同一天的种植建议。

验收包括老存档迁移、四段正确与错误选择、单步保存与刷新、两章往返、重置与导入导出、四段各六组视口以及原首章通关。最新动画平滑记录见美术文档。
