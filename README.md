# 来时的路 · The Way Home

一位穿黑裙、戴黑帽的老妇人，带着一条黑狗，以年老的姿态重新走过姑娘时代。Three.js 绘本叙事游戏，现为从核桃树到回乡尾声的完整可通关版本。

## 本地运行

需要 Node.js 22+。

```sh
npm ci
npm run dev
```

`npm test` 检查存档；`npm run build` 生成静态产物。GitHub Pages 通过 Actions 自动构建，支持仓库子路径。

## 试玩

点击小路或使用 A / D、方向键行走，手机使用方向按钮。走到回忆地点附近，按 E / 空格或点右下角互动。每章结束可进入下一章，也可从旅途手记往返已解锁的章节。声音默认关闭，可开启合成提示音。

| 章 | 故事 | 互动 |
|---|---|---|
| 01 核桃落下来的时候 | 故乡与伙伴 | 敲树、拾核桃 |
| 02 枣树下的光 | 四季里的照料 | 辨树势、环切示意、疏果、剪枝、观察异常 |
| 03 上学路上的月亮 | 捡玉米、深夜白跑学校 | 拾取、线索观察、安静的回程 |
| 04 后座上的人 | 自行车、摩托车、初中分流 | 实时换道避障、减速、回应 |
| 05 去西安的火车 | 高中、住宿、孜然夹馍 | 旅程顺序、宿舍物件、下课路线 |
| 06 再走一遍的那一年 | 两次高考与高复 | 倾听、作息安排、四季顺序 |
| 07 太原的五年 | 建筑学与晋祠 | 制图、模型、写生、古建观察、采光动线、毕业设计 |
| 08 上海的灯 | 通勤与同学合住 | 换乘、生活物件、倾听与边界 |
| 09 写一段关于自己 | 花、油画与介绍 | 浇花、绘画、编辑介绍文字 |
| 尾声 来时的路 | 回旧学校取画册 | 排列十段记忆、步行长卷、完整结局 |

骑行使用上下方向键或车道按钮，摩托车可按住“慢一点”。绘画支持鼠标、触屏、键盘添笔和下载 PNG。介绍文字和画作只保存在游戏存档，不向外部社交平台发送。完整通关后可以散步、重温已完成章节。

进度沿用 localStorage 的 `the-way-home.save.v1`，旧存档自动补齐后续字段。护理每次操作保存，其他谜题每段结束保存；绘画笔触、介绍草稿和长卷排列可中途保存。手记支持导入、导出和重置。无账号、无跨设备自动同步，清除浏览器数据前先导出。

## 当前边界

- 已实现：绘本背景、独立动画角色、跟随犬、落叶、核桃树互动、回忆页、存档。
- 老妇人与黑狗均使用本地 ComfyUI MiniMax H3 连续视频抠绿后的行走循环，步态跟随各自实际移动距离推进。老妇人 58 帧、黑狗由原 32 帧循环经双向光流平滑为 64 帧，并在渲染时平滑过渡。待机另有视频动作：老妇人双脚自然靠近站立，待机时整理头发或抬头远望；黑狗有坐下挠痒、低头嗅闻、侧耳倾听。两者独立随机等待，避免连续重复同一动作，起动作至少错开 3.2 秒；单次播放后冷却，重新移动时收尾。敲树动作暂用竹竿反馈。背景是单幅绘画，尚未拆成独立可移动山坡。
- 九章与回乡尾声均已实现可玩流程，详见 [设计文档](docs/game-design.md)。骑行采用车辆与路线示意，其他新互动在记忆画板内完成，没有另造独立人物姿势。
- 已实际调用本地 MiniMax H3 FL2VA INT8 + 8 步 Turbo LoRA，24fps：老妇人使用 384×576、124 帧原片；黑狗使用 576×384、124 帧行走与 175 帧待机原片。未使用云端生成、双采或超分；当前设备未安装对应超分节点，不能把其他设备的配置视为已可用。

## 屏幕适配

手机横竖屏均可游玩，无需强制旋转。场景保持比例，窄屏相机跟随角色，超宽屏调整取景。界面避开安全区；支持动态视口、触控方向按钮、独立互动按钮和浏览器支持时的全屏模式。手记小屏滚动显示。

本地启动 4173 端口后，`node responsive-check.mjs` 检查六组视口与旋转、按钮布局、弹窗滚动；`node smoke.mjs` 检查完整首章。`node garden-smoke.mjs` 检查旧存档迁移、章节往返、护理全过程与中途刷新；`node garden-responsive.mjs` 检查四段护理在六组屏幕下的布局、点击范围与横向裁切。`node save-browser-check.mjs` 检查浏览器实际导入、下载导出和两章重置。浏览器脚本默认使用本机 Chrome，需要安装 Chrome；`GAME_URL` 可指定线上地址。

`node journey-smoke.mjs` 连续通关第三章至尾声，覆盖实时骑行、建筑、绘画、介绍、长卷与最终结局。`node journey-responsive.mjs` 检查后半程十六类交互页面在六组屏幕下的布局。`node journey-state-browser.mjs` 检查真实触屏绘画、半完成画作、草稿、长卷保存与骑行关闭后的清理。布局脚本需开发服务器，流程脚本可指定 `GAME_URL`。

## 美术

`public/assets/village.png` 使用 GPT imagegen 内置工具生成，以用户提供的秋日乡村画作作为风格参考。提示词见 [美术记录](docs/art-direction.md)。参考图归原作者所有，公开仓库不包含原始参考图片。生成场景用于当前原型，发布商业版本前继续整理资产来源。

本地视频抠绿与图集打包工具为 `scripts/video-to-gait.py`，使用已有 ComfyUI Python 环境中的 PyAV、NumPy、Pillow。先 `--review --output <审阅目录>` 查看连续帧与接缝候选，再指定 `--start 20 --end 78 --stride 56 --output public/assets` 打包；边界为零起始、结束帧不包含。所有帧共用裁剪框，保留原始帧序，不插值伪造中间姿势。原片、绿幕首帧与完整 ComfyUI 工作流归档在本地忽略目录 `test-results/gait/`。

`--name dog --display-height 84.24 --crop 0 0 576 384` 可复用工具处理动物。帧表按长宽比排列，限制在 4096×4096 内。待机原片和工作流归档在 `test-results/idle/`；这些视频均由本机生成，没有调用云端视频服务。

后半程新增七幅场景由内置 imagegen 生成，运行时使用 WebP，逐章加载并释放过期背景纹理。原始 PNG 存在本地忽略目录 `test-results/full-art/`。最终提示词见 [场景提示词](docs/chapter-scene-prompts.json)。Three.js 单独分包，叙事与交互代码独立加载。
