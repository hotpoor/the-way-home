# 来时的路 · The Way Home

一位穿黑裙、戴黑帽的老妇人，带着一条黑狗，以年老的姿态重新走过姑娘时代。基于 Three.js 的绘本叙事游戏，当前为第一章可玩原型。

## 本地运行

需要 Node.js 22+。

```sh
npm ci
npm run dev
```

`npm test` 检查存档；`npm run build` 生成静态产物。GitHub Pages 通过 Actions 自动构建，支持仓库子路径。

## 试玩

点击启程，点击小路或使用 A / D、方向键行走。走到右侧核桃树下，按 E 或点击互动按钮敲树。敲落三颗核桃，在落点附近拾取，完成第一段回忆。手机可使用方向按钮及互动按钮。声音默认关闭，可手动开启合成提示音。

进度存入当前域名的 localStorage（`the-way-home.save.v1`）。手记支持导入、导出和重置；无服务器、无账号、无跨设备自动同步。清除浏览器数据会丢失本地存档。

## 当前边界

- 已实现：绘本背景、独立动画角色、跟随犬、落叶、核桃树互动、回忆页、存档。
- 老妇人与黑狗均使用本地 ComfyUI MiniMax H3 连续视频抠绿后的行走循环，步态跟随各自实际移动距离推进。老妇人 58 帧、黑狗由原 32 帧循环经双向光流平滑为 64 帧，并在渲染时平滑过渡。待机另有视频动作：老妇人双脚自然靠近站立，待机时整理头发或抬头远望；黑狗有坐下挠痒、低头嗅闻、侧耳倾听。两者独立随机等待，避免连续重复同一动作，起动作至少错开 3.2 秒；单次播放后冷却，重新移动时收尾。敲树动作暂用竹竿反馈。背景是单幅绘画，尚未拆成独立可移动山坡。
- 后续人生章节、枣树护理、骑行、建筑小游戏尚未实现，详见 [设计文档](docs/game-design.md)。
- 已实际调用本地 MiniMax H3 FL2VA INT8 + 8 步 Turbo LoRA，24fps：老妇人使用 384×576、124 帧原片；黑狗使用 576×384、124 帧行走与 175 帧待机原片。未使用云端生成、双采或超分；当前设备未安装对应超分节点，不能把其他设备的配置视为已可用。

## 屏幕适配

手机横竖屏均可游玩，无需强制旋转。场景保持比例，窄屏相机跟随角色，超宽屏调整取景。界面避开安全区；支持动态视口、触控方向按钮、独立互动按钮和浏览器支持时的全屏模式。手记小屏滚动显示。

本地启动 4173 端口后，`node responsive-check.mjs` 检查六组视口与旋转、按钮布局、弹窗滚动；`node smoke.mjs` 检查完整首章。浏览器脚本默认使用本机 Chrome，需要安装 Chrome；`GAME_URL` 可指定线上地址。

## 美术

`public/assets/village.png` 使用 GPT imagegen 内置工具生成，以用户提供的秋日乡村画作作为风格参考。提示词见 [美术记录](docs/art-direction.md)。参考图归原作者所有，公开仓库不包含原始参考图片。生成场景用于当前原型，发布商业版本前继续整理资产来源。

本地视频抠绿与图集打包工具为 `scripts/video-to-gait.py`，使用已有 ComfyUI Python 环境中的 PyAV、NumPy、Pillow。先 `--review --output <审阅目录>` 查看连续帧与接缝候选，再指定 `--start 20 --end 78 --stride 56 --output public/assets` 打包；边界为零起始、结束帧不包含。所有帧共用裁剪框，保留原始帧序，不插值伪造中间姿势。原片、绿幕首帧与完整 ComfyUI 工作流归档在本地忽略目录 `test-results/gait/`。

`--name dog --display-height 84.24 --crop 0 0 576 384` 可复用工具处理动物。帧表按长宽比排列，限制在 4096×4096 内。待机原片和工作流归档在 `test-results/idle/`；这些视频均由本机生成，没有调用云端视频服务。
